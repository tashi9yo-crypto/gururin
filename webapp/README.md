# 연화생전 웹 리더

`index.html` 한 파일에 책 전체가 들어 있습니다. 브라우저로 열면 바로 읽을 수 있고, 인터넷이 없어도 열립니다(인터넷이 있으면 본문 글꼴을 Google Fonts에서 받아 옵니다).

## 기능

- 표지, 부(部) 표제 쪽, 장 표제와 머리 게송
- 책처럼 넘기기: 넓은 화면은 두 쪽 펼침, 좁은 화면은 한 쪽. 화면 좌우를 누르거나 ←/→ 키, 휴대폰은 좌우로 밀기
- 목차(읽은 장 표시), 책갈피(B 키), 읽던 곳 기억(이어 읽기)
- 보기 설정: 배경(자동·밝게·세피아·어둡게), 글꼴(명조·바탕·고딕), 글자 크기, 줄 간격, 보기 방식(자동·한 쪽·펼침·스크롤)
- 화면 가운데를 누르면 도구 막대가 숨겨집니다
- 책 끝에 부록(장별 출처와 각색, 영상화 노트)

## 원고를 고친 뒤 다시 만들기

```bash
python3 webapp/build.py
```

`소설/*.md`와 부록을 읽어 `webapp/template.html`에 넣고 `webapp/index.html`을 새로 씁니다. 부(部)의 나뉨은 `build.py`의 `PARTS`에서 정합니다.
