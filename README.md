# 연화생전(蓮花生傳) — 설산을 넘는 스승

구루 린뽀체(빠드마삼바와)의 전기를 바탕으로 각색한 장편 소설.

8세기, 낮에 쌓은 절이 밤마다 무너지는 눈의 나라 티벳. 젊은 왕은 붓다의 법을 세우려 하나 이 땅의 신과 귀신들이 길을 막는다. 왕의 부름을 받은 한 수행자가 인도에서 히말라야를 넘는다. 그는 귀신을 죽이지 않는다. **맹세하게** 만든다.

## 읽기

- **웹앱(책처럼 읽기)**: [`webapp/index.html`](webapp/index.html)을 브라우저로 여세요. 파일 하나에 책 전체가 들어 있어 인터넷 없이도 열립니다.

## 이 소설의 뼈대

서유기처럼 관문을 하나씩 넘는 여정이되, 각 관문의 귀신은 바깥의 적인 동시에 안의 번뇌입니다. 교만은 산을 세우고, 분노는 호수를 끓이고, 어리석음은 눈보라 속을 맴돌게 하고, '나'라는 생각은 모든 것을 삼키려 듭니다. 스승은 그것들을 없애지 않고 방향을 바꿔 수호자로 만듭니다. 번뇌를 끊지 않고 지혜로 바꾸는 것, 그것이 티벳 불교가 전하는 길입니다.

이번 개정에서 여정의 조복 장면과 삼예 이후의 이야기는 상링마(41장) 한국어 번역을 기준으로 원전에 맞게 고치고, 원전의 재미있는 장면(벼락이 마른 콩알이 됨, 탕라의 맛없는 빵, 입맛 까다로운 마첸, 해를 붙잡은 남카이 닝뽀, 세 번 타는 왕의 옷, 전생에 벌레였던 스승)을 살렸습니다.
