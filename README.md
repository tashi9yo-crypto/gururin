# 연화생전(蓮花生傳) — 설산을 넘는 스승

구루 린뽀체(빠드마삼바와)의 전기를 바탕으로 각색한 장편 소설.

8세기, 벼락과 홍수와 역병으로 신음하는 눈의 나라 티벳. 젊은 왕은 붓다의 법을 세우려 하나 이 땅의 신과 귀신들이 길을 막는다. 왕의 부름을 받은 한 수행자가 인도에서 히말라야를 넘는다. 그는 귀신을 죽이지 않는다. **맹세하게** 만든다.

## 주요 인물

| 인물 | 설명 |
|---|---|
| **구루 린뽀체** | 연꽃에서 태어난 스승. 빠드마삼바와, 빼마 중내 |
| **바 쌜낭** | 왕의 사신. 무엇이든 받아 적는 학자. 훗날 티벳 최초의 승려 가운데 한 사람 |
| **낙남 도제 뒤좀** | 왕의 사신. 귀신은 칼로 베면 된다고 믿는 무사. 훗날 스물다섯 제자 가운데 한 사람 |
| **노르부** | 열세 살 야크 목동. 역병으로 부모를 잃음. *(창작 인물)* |
| **티쏭 데쩬** | 티벳의 법왕 |
| **샨따락시따** | 날란다의 큰스승. 삼예의 초대 주지 |
| **예셰 초걜** | 카르첸의 공주. 스승의 모든 가르침을 기억하고 기록한 수제자 |
| **도제 렉빠** | 염소를 탄 대장장이 신. 조복된 뒤 일행에 합류 |

## 이 소설의 뼈대

서유기처럼 관문을 하나씩 넘는 여정이되, 각 관문의 귀신은 바깥의 적인 동시에 안의 번뇌입니다. 교만은 산을 닫고, 분노는 호수를 끓이고, 어리석음은 눈보라 속을 맴돌게 합니다. 스승은 그것들을 없애지 않고 방향을 바꿔 수호자로 만듭니다. 번뇌를 끊지 않고 지혜로 바꾸는 것, 그것이 티벳 불교가 전하는 길입니다.
